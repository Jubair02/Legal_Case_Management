     5→     5→## Project Overview
     6→     6→- Web-based legal case management for law firms/chambers in Bangladesh.
     7→     7→- Brand: **AinSheba (আইনসেবা)** — tagline "Legal Case Management — Bangladesh".
     8→     8→- Stack: Next.js 16 App Router + TypeScript + Tailwind 4 + shadcn/ui (New York), Prisma + SQLite (`db/custom.db`), JWT session cookie auth (jose), local file uploads (`uploads/` folder).

    12→    12→## CRITICAL ARCHITECTURE RULES
    13→    13→1. **The user can ONLY see the `/` route.** The whole app is a client-side SPA inside `src/app/page.tsx`. NO other page routes are allowed. API routes under `src/app/api/**` are fine.
    14→    14→2. No `bun run build`. Dev server runs on port 3000 (`bun run dev`, log at `/home/z/my-project/dev.log`).
    15→    15→3. Use `import { db } from "@/lib/db"` for Prisma.
    16→    16→4. All API responses: success `{ "data": ... }`, failure `{ "error": { "message": string, "code": string } }` with proper HTTP status.
    17→    17→5. Auth: httpOnly cookie `lcm_session` (JWT). Never trust client role — enforce on server.
    18→    18→6. NO new external packages without necessity; `jose` already installed.
    19→    19→7. Next 16 route handler params are async: `{ params }: { params: Promise<{ id: string }> }` → `const { id } = await params`. Same for `cookies()` → `await cookies()`.
    20→    20→8. Files uploaded to `uploads/<caseId>/...`; served via `/api/files/[documentId]`.
    21→    21→9. SQLite + Prisma: **no enums, no array fields** — statuses/types are plain strings.
